Make PC games with Premium Engine

A C++ game engine with an editor laid out like Unreal Engine 5. Build levels, write scripts, press Play, and package your game as a Windows program.

Download for Windows Open the web version (0.1)

Windows 10 / 11 · 64-bit · OpenGL 3.3 graphics. Unzip and run PremiumEngine.exe — no installer.

The editor you already know

Same menus, same order: FileEditWindowToolsBuildSelectActorHelp

Viewport

Fly with the right mouse button and W A S D, move / rotate / scale gizmo with snapping, Perspective, Top, Front and Right views, Lit, Unlit, Wireframe.

Outliner & Details

Every actor in the level. Drag to attach. Edit transform, mesh, material, physics, lights, text and scripts.

Content Browser

Levels, materials, scripts and shapes. Drag a material onto an actor, or a shape into the level.

Real renderer

Physically based lighting, sun shadows, point and spot lights, sky light, fog and ACES tone mapping. OpenGL 3.3.

Jolt Physics

Simulated bodies, collisions and a walking, jumping player. The same physics engine used in big console games.

JavaScript scripts

onStart, onUpdate, onOverlap, onHit, onKey. A code editor with colours, error lines and a full API reference.

Play in the editor

First Person, Third Person or Spectator. Press Play, Esc stops. Or run it in its own window.

Package for Windows

Platforms › Windows makes a folder with your game's .exe. Zip it and share it.

Undo everything

Undo / redo, copy, paste, duplicate, autosave, map check, statistics and console commands.

Start in a minute

  1. Download the zip and unzip it anywhere.
  2. Run PremiumEngine.exe, pick First Person, type a name and press Create.
  3. Press the green Play button. Collect the coins, try the jump pad.
  4. Change things: drag shapes in, edit materials, open a script and press F7.
  5. Platforms › Windows — your game is in Documents\PremiumEngine\Builds.
Premium Engine is an experimental project of Premium Games. Projects use the .pge.json format and open in both the Windows engine and the web version. Open source libraries: SDL2, Dear ImGui, ImGuizmo, Jolt Physics, QuickJS-ng, GLM, nlohmann/json.
